# Skills and reviewed learning

A skill is a reusable procedure with the inputs, tools, output requirements and checks needed for a bounded task. In PuranOS, skills connect specialist responsibility to a repeatable engineering workflow.

## What is retained

A useful skill explains where the source information comes from, which shared implementation performs the work, what the next specialist receives and how missing information is handled. It should point to the canonical writer and renderer instead of encouraging a project-local duplicate implementation.

The engineering-package workflow coordinates retained source records, equipment and instrumentation schedules, narrative content, review gates and document rendering. A repeated task can reuse that procedure while keeping each project’s basis and decisions distinct.

## How a correction enters later work

1. Actual work reveals a repeatable failure or missing check.
2. The responsible specialist identifies the underlying shared tool or procedure.
3. A reviewed fix changes the implementation, skill or instruction and receives appropriate verification.
4. The change is committed with its purpose and scope.
5. A later task uses the corrected version. An existing project adopts it through a defined revision or replay.

This is human-directed learning in the engineering system. It does not imply automatic model retraining, infallible agent memory or silent updates to issued work.

## Coded visual production is another example

The production personas use the same principle for explanatory films. Coded geometry, deterministic timelines and reusable rendering components make camera motion, equipment identity, typography and continuity directly editable. Reviews can target a precise frame or sequence. Accepted fixes belong in the shared production workflow, with provenance and rebuild instructions retained.

Generated media can be useful for suitable assets, but it does not offer the same control over engineering geometry and continuity. A visually convincing animation remains an illustration unless explicitly supported as a representation of installed work.
