# Specialist roles and engineering handoffs

A persona combines a defined responsibility, tool exposure and reusable working instructions. It is a role for an AI agent, not a substitute for the person accountable for engineering acceptance.

## Roles in an engineering package

| Role | Primary contribution | Handoff |
| --- | --- | --- |
| pe-lead | Coordinates scope, dependencies, package checks and review. | Defined tasks and an inspectable package. |
| pe-process | Feed characterization, process simulation, connected balances and operating duties. | Retained model basis and results for sizing and design. |
| pe-cad | Process drawings, layout, equipment placement, connections and service access. | Registry-bound geometry and drawing evidence. |
| pe-deliverables | Equipment, load and instrumentation schedules and package composition from shared records. | Documents tied to their underlying engineering information. |
| pe-electrical | Power and instrumentation engineering. | Discipline requirements and schedules. |
| pe-automation | PLC/TIA and SCADA implementation work within its authorized scope. | Controls implementation artifacts; distinct from advisory plant diagnosis. |
| project-finance | Financial assumptions, archived scenarios, projections and comparison with actuals. | A reviewable financial case with its baseline retained. |
| procurement | Supplier evidence and commercial/equipment comparisons. | Offers and exclusions kept distinct from requirements. |
| maintenance | Equipment history, maintenance workflows and operating investigations. | Evidence-backed findings and authorized maintenance tasks. |

Other specialist roles cover mechanical, structural, separation, water-supply and narrative work, as well as commercial and administrative functions. The current configuration and task context determine the tools a run can actually use.

## How the team remembers

The lead gives a specialist the task, source revision and acceptance criteria. Independent investigations may run concurrently. Results return as records and artifacts with enough information to inspect the basis; the next specialist consumes the agreed information rather than guessing from a conversation summary.

An engineering package can carry an unresolved question, its owner and its release consequence. A successful calculation does not erase that question or authorize the document.

When actual work reveals a repeatable error, a reviewed correction belongs in the shared implementation or skill. Existing project results retain their earlier basis. A new revision or replay adopts the change deliberately.

## Parallel work has a coordination cost

Agents can prepare independent analyses in parallel. Work that changes the same engineering record needs an explicit writer and ordering. The lead must reconcile alternatives and dependencies before a package can be accepted. More simultaneous runs do not, by themselves, establish faster delivery or a better design.
