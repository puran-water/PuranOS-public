# PuranOS Studio

PuranOS Studio is the browser review surface for retained engineering publications. It connects process drawings, review-stage concept geometry and engineering evidence through shared equipment identities and a pinned source revision.

| Review gate | Publication content |
| --- | --- |
| R1 | BFD sheets and balance; optional concept geometry, stills and sizing basis. |
| R2 | PFD sheets and coordinated lists; optional sizing basis. |
| R3 | P&ID sheets, review-stage concept geometry and line list. |

![PuranOS Studio live held review with identifying labels and detailed values concealed](https://raw.githubusercontent.com/puran-water/.github/main/profile/assets/studio-review.png)

*Live Studio interface, captured for this overview. Project identifiers and detailed values are concealed. The publication remains a held review with unresolved conditions; it is not an issued design.*

A reviewer can inspect linked diagram and concept appearances, open retained properties and compare the basis with the drawing. File hashes, source identity and supersession history keep the reviewed publication identifiable. Available panes depend on the content of the selected publication.

The viewer serves authorized project content. It does not run a new engineering calculation, write the design registry or turn a review publication into an issued document. Private project records are not public demo data.

Studio follows the engineering package produced by [sizing-to-balance and the proposal/BEP workflows](workflows.md). [Ask for a demonstration](https://puranwater.com/contact/).
