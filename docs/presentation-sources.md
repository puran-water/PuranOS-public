# Keeping this presentation current

The working monorepo is the implementation source of truth. Reviewed public prose lives under its `docs/public-presence` directory. Public engineering-server README assets belong to the exact export recipes and rights receipts, so their normal mirror carries updates without changing public branch history by hand.

Other public repositories keep their own upstream implementation documentation and a scoped Puran Water integration note. Archived candidate notices must retain archived status; a documentation edit is not a code release.

The website revamp has its own branch, claim ledger and sanitization checks. Its schema snapshots and historical qualification reports keep their original dates. Before changing a claim, inspect the implementation and the actual public export. Before adding a screenshot, verify permission for its content, conceal private identifiers and retain its review standing.
